## NumberBaseball (숫자 야구)



언리얼 엔진 5.6 C++로 만든 멀티플레이 숫자 야구 게임입니다.

서버가 정한 3자리 숫자를 플레이어들이 채팅 입력창으로 추측하고, 3번의 기회 안에 3S를 달성하면 이기는 게임입니다.





1\. 프로젝트 소개



내일배움캠프 언리얼 10기 과정 중 CH4 - 멀티플레이 게임 개발 강의를 통해 진행된 과제입니다.



학습 목표

\- \*\*멀티플레이어 기초:\*\* Server/Client 간의 역할 분담과 RPC 통신 이해

\- \*\*PlayerState :\*\* 플레이어의 개별 데이터(시도 횟수 등)를 독립적으로 관리/동기화하기

\- \*\*GameModeBase:\*\* 게임의 전체적인 규칙(판정, 승리 조건)을 서버 측에서 제어하기

\- \*\*UMG 연동:\*\* C++ 로직의 결과를 위젯을 통해 플레이어에게 시각적으로 전달하기

\- \*\*유효성 검사:\*\* 잘못된 입력이 서버 로직을 해치지 않도록 방어 코드 작성하기



2\. 게임 규칙

1. 게임이 시작되면 서버가 1\~9 사이의 중복 없는 3자리 정답을 만듭니다. (예: 386, 594)

2\. 각 플레이어에게 3번의 기회가 주어집니다.

3\. 입력은 3자리의 숫자로만 할 수 있습니다. 



&#x20;3-1. 3자리 미만이나 초과되는 숫자를 입력할 경우

&#x20;3-2. 숫자 외의 문자를 포함할 경우

3-3. 중복 되는 숫자를 입력할 경우



위와 같이 입력 조건을 만족하지 못했을 경우 다시 입력하세요 문구가 출력됩니다. 이때 도전 기회는 소진되지 않습니다.



4\. 입력한 숫자와 정답을 비교해 결과를 알려주며 아래와 같은 의미를 가집니다.

S(Strike) - 숫자와 자리가 모두 일치할 경우

B(Ball) - 숫자는 일치하지만 자리가 다를 경우

OUT - 일치하는 숫자가 하나도 없을 경우



5\. 입력할 때마다 남은 기회가 표시됩니다.

Player1: 683 -> 1S2B \[1/3]



6\. 승리 조건

누구든 3번의 기회 안에 3S를 맞히면 즉시 승리(위젯으로 결과 출력)

모든 플레이어가 기회를 전부 소진했음에도 3S를 달성하지 못하면 무승부



게임의 결과가 출력되고 나면 정답과 기회가 전부 리셋되어 새로운 게임을 시작할 수 있습니다.
